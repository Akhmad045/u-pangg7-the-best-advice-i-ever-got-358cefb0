One sentence about the best advice the writer ever received — the kind
that only lands years later, when the cheap thing finally breaks in
your hand.

## The entry

> My uncle, wiping grease off his hands, said a cheap tool costs you twice: once when you buy it, and once when it breaks in your hand.

133 characters, one line. A real person, a real moment: an uncle with
grease on his hands, and advice that holds for tools, hires, shortcuts
and everything else you buy twice.

## How it works

`main.py` writes exactly that sentence to `/output/entry.txt`. It checks
the entry gate first (1–200 characters, a single line, no leading or
trailing whitespace) and refuses to write a sentence that fails it.

```sh
python3 main.py              # write the entry to /output/entry.txt
python3 main.py --self-test  # gate checks + boundary probes + write round-trip
python3 main.py --info       # print chars, bytes, sha256 and gate verdict
```
